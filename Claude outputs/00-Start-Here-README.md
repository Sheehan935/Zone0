# 00 — Start Here

## What this folder is

Orientation material for ZONE0-OS: the rules, standards, current state, and
change history of the operating system.

**Authority lives in [ZONE0-OS — START HERE](https://docs.google.com/document/d/1h65M64EbiE8o4y7zshuWCRQGdNzRY2970qwiK6kLenI/edit), not in this README.**
That document decides what owns which truth. This file only says what is in
this folder and where things go.

## What's in here

- **Current State** — the operating state of the system as it stands now
- **Standards & Principles** — rules and standards that apply to all other zones
- **Master Index** — the index of ZONE0-OS documents
- **Change Log** — the record of changes to the operating system
- **Onboarding** — how a person or an agent gets started
- **Templates** — reusable document templates

## Routing rules

- Global architecture guidelines, operating principles, and cross-functional
  decisions → this zone.
- Technical code decisions → `docs/decisions.md` in the GitHub repo, not here.
- Business, operations, marketing, sales, product, digital and systems
  material → zones 01–07, not here.

## Deliberately not here

- **Verified production state** → `PROJECT-TRUTH.md` in the GitHub repo.
- **Tasks** → the Zone Zero Control Center. There is no task list in this
  folder and none should be created here.
